# E-Commerce Customer Behavior & Conversion Analysis

## 📌 Project Overview

This project analyzes e-commerce customer behavior using event-level
data to understand the customer journey from product viewing to purchase.

## 🎯 Objectives

- Analyze customer engagement
- Measure the e-commerce conversion funnel
- Identify customer drop-off points
- Identify high-performing products
- Analyze repeat purchasers
- Identify peak purchasing hours
- Provide actionable business recommendations

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 📊 Key Analysis

The project includes:

- Customer funnel analysis
- View → Add to Cart → Purchase conversion
- Product performance analysis
- Repeat customer analysis
- Purchasing-hour analysis
- User behaviour heatmap
- Business recommendations

## 📈 Key Findings

- View-to-purchase conversion rate: 0.78%
- Repeat purchaser rate: 22.44%
- Peak purchasing hour: 17:00
- Highest-converting product: Item 305675

## 💡 Business Recommendations

1. Improve product-page conversion.
2. Reduce cart abandonment.
3. Promote high-converting products.
4. Target customers during peak purchasing hours.
5. Encourage repeat purchases through personalized offers.

## 📂 Dataset

The analysis uses the RetailRocket e-commerce dataset.

Dataset source:
https://www.kaggle.com/retailrocket/ecommerce-dataset

## 🚀 How to Run

Open the `.ipynb` notebook using Google Colab or Jupyter Notebook
and run the cells from top to bottom.
